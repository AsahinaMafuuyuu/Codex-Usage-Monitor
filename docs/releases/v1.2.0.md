# Codex Usage Monitor v1.2.0

Phase 28 introduces the managed release and CLI lifecycle for the local Codex Usage Monitor.

## Highlights

- `package.json.version` is the single application-version source.
- Dedicated `codex-usage-monitor` CLI with `start`, `open`, `--version`, `--update`, `update --check`, `rollback`, and `doctor`.
- Exact loopback endpoint with persistent local browser authorization instead of per-start token URLs.
- Windows Managed Install under `%LOCALAPPDATA%\CodexUsageMonitor` with immutable version directories and a stable command shim.
- Stable GitHub Release updates verified by external manifest, SHA-256, embedded build identity, offline self-check, and atomic current-pointer switching.
- SQLite compatibility gates, online backups, managed-data migration, and explicit restore rollback.
- Release CI creates a Draft GitHub Release only after the complete verification/build gate succeeds; publishing remains a maintainer action.

## Compatibility

- Windows 11
- Node.js 24 or newer
- SQLite schema 15, storage compatibility epoch 1

The release/update subsystem does not change Request Ledger accounting, subscription-equivalent pricing semantics, diagnostics semantics, or the read-only `.codex` boundary.
